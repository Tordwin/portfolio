# Edwin Chen's portfolio

A portfolio showcasing my projects, experience, skills, and education in Computing and Information Technology at RIT.

[View the live portfolio](https://people.rit.edu/~ec7233/portfolio/)

## About the site

The site features The Crafty Studio and seven project cards, along with my work experience, technical skills, education, resume, and contact links. Project cards can be filtered by category and opened for more details. The layout adapts to different screen sizes and supports reduced motion. Project details remain accessible without JavaScript.

## Project structure

- `index.php` contains the main page and its sections.
- `data/projects.php` holds project details, categories, and image paths.
- `header.php` and `footer.php` provide shared navigation, metadata, and links.
- `global.css` controls the site's styling and responsive layout.
- `main.js` handles navigation, project filters, and project dialogs.
- `images/` contains the portrait and project screenshots. The original portrait is also used as the browser tab icon.
- `assets/edwin-chen-resume.pdf` is the downloadable resume.

## Deployment

Deploy the PHP files and assets to a PHP-capable web host. No database, dependency installation, or build step is required. A local preview must support PHP to render the complete site.
